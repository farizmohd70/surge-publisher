**First release title:** Surge Publisher v1.0.0

**First release notes:**
First public release of Surge Publisher, a desktop app for publishing static sites to Surge.sh.

- One-click publish, preview and Publish all, with live progress
- Pre-publish safety checks and gitignore-style exclude rules
- Multiple Surge accounts, with tokens encrypted by the OS
- Pin, archive and categorise sites; drag to reorder
- Auto-publish on file change, schedules, health checks, tray icon
- Drop-in files with automatic backup and undo
- Publish history with roll back / roll forward
- Light, dark and six UI styles

Download the portable Windows `.exe` below. Requires Node.js.
