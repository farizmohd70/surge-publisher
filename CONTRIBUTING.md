# Contributing

Thanks for helping improve Surge Publisher!

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Install and run: `npm install` then `npm start`
3. Make your change. Keep it small and focused, and match the existing code style (plain JavaScript, no framework).
4. Test it by hand: add a site, publish, and check the output log.
5. Commit and open a pull request describing what changed and why.

## Reporting bugs

Open an issue and include your OS, app version, and the steps to reproduce.
Please **never paste Surge tokens or passwords** into an issue.
